SocialOne 

Centralized Social Dashboard
SocialOne is a modern, feature-rich Android web browser and social media aggregator designed to streamline your digital life. It allows users to manage multiple social accounts, browse the web privately, and sync their data across devices using a centralized, highly customizable dashboard.

Key Features
1. Multi-Tab Browsing System
•
  Persistent Tabs: Open multiple websites and switch between them seamlessly.
•
  Tab Locking: "Lock" important tabs to prevent them from being closed or paused.
•
 Tab Switcher: A visual grid preview of all open tabs for quick navigation.
2. Dual-Mode UI Design
•
Fixed Mode (Default): A stable, professional bottom bar for reliable navigation.
•
Advanced Animations: A toggleable "Dynamic Mode" featuring a floating bottom bar and auto-hiding controls that respond to your scrolling, perfect for modern, high-performance devices.

3. Integrated Dashboards
•
Home Dashboard: Quick access to recently visited sites and personalized bookmarks.
•
Quick Access Messages: Dedicated quick-access for professional messaging platforms like LinkedIn, Messenger, and Gmail.
•
Incognito Mode: Browse privately with a dedicated dark-themed UI. History and cookies are cleared automatically when the tab is closed.

4. Cloud Sync & Security
•
Firebase Integration: Real-time synchronization of tabs, bookmarks, and browsing history using Firebase Firestore.
•
Google Authentication: Secure login to keep your personal dashboard consistent across different Android devices.
•
Guest Access: Full functionality available even without an account.

5. Advanced Search Capabilities
•
Global Search: Type a query once and search across multiple selected platforms (Google, Bing, Twitter, etc.) simultaneously.
•
Customizable Engines: Choose your preferred default search engine (DuckDuckGo, Brave, Ecosia, etc.) in the settings.
•
Search Predictions: Integrated autocomplete suggestions to speed up your browsing.

6. Content Creation
•
Post Composer: A built-in tool to draft text and attach media (Images/Videos) using the modern Android Photo Picker, ready to be shared across your social networks.
 
Tech Stack
•
Language: Java / Kotlin
•

•
Backend: Firebase (Auth, Firestore)
•

•
Web Engine: Advanced Android WebView with Custom Chrome Clients
•
Architecture: Adaptive layout supporting Light and Dark modes.
